# tailz.dev

OSS home for **Turbotailz**. Console-core Nuxt 4 site. Not a studio, not a gamer dashboard.

```
pnpm install
GITHUB_TOKEN=$(gh auth token) pnpm dev
GITHUB_TOKEN=$(gh auth token) pnpm build
pnpm deploy
```

Apex: [tailz.dev](https://tailz.dev). Subdomains (`morpheus`, `luckperms`, `syscraft`, homelab) are other projects — leave them.
